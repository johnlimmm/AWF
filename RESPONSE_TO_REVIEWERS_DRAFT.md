We sincerely thank the Associate Editor and all reviewers for their careful
and constructive comments. We performed a clean re-evaluation rather than
only revising the text. The revision (i) corrects the LTE trace definition,
(ii) calibrates all user posteriors, (iii) selects every policy parameter on
validation data, (iv) adds the previously missing policy sweeps and ablations,
(v) evaluates held-out and temporally replayed network traces, shared-link and
homogeneous access, and correlated BCI errors, (vi) compares AWF with a
finite-horizon Bellman solution for the small committee, and (vii) adds paired
statistical tests and runtime/memory measurements. We have also narrowed the
claims where the new evidence does not support a stronger conclusion. In
particular, we retain the margin condition as an interpretable sufficient
stopping certificate, but no longer present it as an independently measured
source of performance gain.

## Reviewer 1

### Offline confusion matrices and non-stationary reliability

We agree. The revised manuscript now distinguishes the current experimental
estimator from a deployment implementation. The experiment estimates each
user's confusion matrix and temperature only from validation data. In a live
system, the same sufficient statistics can be updated with an exponentially
weighted confusion matrix when delayed labels or high-confidence pseudo-labels
become available, with a lower bound on effective sample size and a fallback
to the scalar reliability model. We add fatigue, session drift, and day-to-day
EEG variability to the limitations and future-work discussion. We do not
claim that the current offline matrix solves long-term non-stationarity.

### Quality of the one-step approximation

We added a non-clairvoyant finite-horizon dynamic-programming reference for
Zhou2016 (`N=4`, `C=3`). It integrates every future arrival subset and every
confusion-matrix report combination on a time grid; it never observes the
realized future delay, posterior, label, or test outcome. With a 5-ms grid,
the mean objective is 0.05758 for DP and 0.06042 for AWF, giving an average
AWF gap of 0.00284. Accuracy on the first three seeds is unchanged across
2.5-, 5-, and 10-ms grids. We now explicitly describe the DP result as exact
for the discretized conditional-independence model, not as an exact solution
to every real deployment.

### Conditional independence of BCI and network behavior

We now state this assumption explicitly. We additionally use a Gaussian
copula to increase cross-user error correlation to 0.2 and 0.5 while
preserving each user's marginal class accuracy. At correlation 0.5, AWF
remains close to Full-Wait accuracy while retaining substantially lower
latency, although all committee-fusion gains decrease. We also discuss that
device compute time, battery state, and network quality may be coupled in a
real system and are not identified by the present public datasets.

### Complexity and scalability

We add an explicit worst-case complexity analysis. With event-driven updates,
the direct implementation is `O(N^2 C^2)` in the wait-until-all worst case and
uses `O(N C^2 + N S)` belief state for `S` empirical delay samples. Prefix
sums reduce the exact empirical residual-wait calculation from `O(S)` to
`O(log S)` per query. On the experiment machine, the Python implementation at
the largest evaluated configuration (`N=10`, `C=7`, `S=40,000`) takes 3.28 ms
median and 7.36 ms at the 95th percentile, using approximately 6.4 MB of
policy state. These are software measurements, not hardware-independent
guarantees.

### Statistical significance

We added paired seed-level Wilcoxon tests over the 15 deployment seeds and
trial-level exact McNemar tests as a secondary analysis. The revised claims
follow the seed-level tests. In particular, AWF and Confidence-Stop do not
have a significant accuracy difference on any dataset. AWF latency is
significantly lower on BNCI2014_001 and Weibo2014, but not on Zhou2016. These
conclusions are unchanged after Holm correction across the seven AWF-versus-
baseline comparisons within each dataset.

### Broader future work

The revised discussion includes online reliability adaptation, semantic
communication, edge scheduling, constrained uplink polling, and adaptive user
selection.

## Reviewer 2

### Confusion-matrix risk versus posterior fusion

We clarified that these objects have different roles. An arrived response is
fused using its full calibrated posterior vector. A missing response has no
posterior yet; its validation confusion matrix is used only to integrate the
possible future hard report and estimate expected risk reduction. Thus the
confusion matrix predicts the value of waiting, while posterior log-pooling
forms the current decision. We also add a scalar-accuracy ablation, which is
weaker than the full class-conditional matrix.

### 4G RTT versus one-way delay

We revised both the implementation and text. The UCC field is `PINGAVG` RTT,
and the simulation uses `PINGAVG/2` as an explicitly stated one-way
approximation. We also found that the old code pooled HSPA-family fallback rows
while the paper labeled the tier LTE. The revision keeps only
`NetworkMode == "LTE"` and rebuilds the cache automatically. The revised
LTE-only one-way statistics are `n=663`, p50/p95/p99 =
42.0/53.0/162.2 ms, with 1.16% mean loss. The old 67% arrival-by-50-ms
statement is replaced by 88.85%.

### Fair parameter selection

First-k, Confidence-Stop, Anytime-cBCI, Arrival-Only, Throughput-Stop,
Entropy-Gain, and AWF are all selected on validation collaborative trials with
the same accuracy-latency objective. The selected parameter is frozen before
test evaluation. The frontier additionally shows complete sweeps including
limiting endpoints.

### Trace-driven limitations

We expand the limitation section. This is not a live multi-user BCI testbed.
In particular, UCC is a 1-Hz application-layer KPI log from a non-rooted
Android device, not a packet-level uplink-delay trace. `RTT/2` ignores path
asymmetry. The replay experiments preserve the measured short-term sequences
but do not reconstruct transport retransmission, routing, or protocol queues.

### 6. Posterior calibration and per-user accuracy

We fit one scalar temperature per user on validation NLL and apply it to test

### 7. Contribution of the margin stage

**Response:** We agree that the submitted sensitivity result did not establish
an independent empirical gain from the margin stage. We nevertheless retain
the condition because it has a simple, parameter-interpretable role that is
different from the waiting-value calculation. Let \(k^*\) and \(k^{(2)}\)
denote the classes with the largest and second-largest fused log beliefs. If

\[
L_{k^*}(t)-L_{k^{(2)}}(t) \geq
\log\!\left(\frac{C-1}{\alpha}\right),
\]

then every non-leading class has probability no greater than the second-ranked
class, and therefore the normalized leading-class belief satisfies

\[
p_{k^*}(t) \geq \frac{1}{1+\alpha}.
\]

For the default \(\alpha=10^{-3}\), this is a fused-belief concentration of at
least approximately 0.999. Thus, the margin test is an inexpensive sufficient
stopping certificate under the calibrated-belief model; it is not a guarantee
that the predicted class is correct, and it is not necessary for AWF to stop.

We now report its observed role directly. The margin condition is recorded as
the stopping reason in 29.9% of BNCI2014_001 trials, 13.5% of Zhou2016 trials,
and 9.7% of Weibo2014 trials on average over 15 seeds. However, the explicit
no-margin ablation produces exactly the same seed-level accuracy and mean
latency in all three datasets because the waiting-value rule is already
non-positive at the corresponding stopping events. We therefore retain the
margin as a conservative, interpretable fast-stop condition, report its
empirical redundancy, and remove any claim that it independently improves the
reported accuracy--latency tradeoff.

**Change in the manuscript:** We have revised the margin-stage description to
state the above sufficient-belief bound and its limited role. We have also
added the trigger rates and the no-margin ablation to [Table/Figure X] and
revised the component-level claim in [Page X, Lines Y--Z].

## Reviewer 6

### Practical necessity and scope

We agree that the submitted manuscript did not sufficiently delimit the use
case. We now frame AWF as post-inference edge fusion for repeated or closed-loop
collaborative inference, not as a way to shorten multi-second EEG acquisition.
We explicitly state that the value of tens of milliseconds depends on the
feedback/control loop and must be validated in a live application.

### Originality beyond generic distributed stopping

We narrow the novelty claim. AWF is not the first distributed early-stopping
idea. Its specific contribution is a class- and user-conditional decision-risk
value for a missing BCI report, multiplied by its deadline-conditioned arrival
probability and evaluated under heterogeneous wireless access. The revised
comparison against decision-blind arrival/throughput and generic entropy
policies is intended to isolate this contribution.

### Calibration and log-pooling

We add validation-only temperature scaling and NLL/Brier/ECE reporting as
described above. We also clarify that multiplying posteriors can amplify
overconfidence, which is precisely why the calibrated and raw variants are
both retained.

### Interdependence between users

We explain that the public datasets are not simultaneous and that independence
is induced by trial construction. The correlated-error and shared-link
experiments test two departures from independence, but a simultaneous
multi-user wireless cBCI dataset remains necessary for external validity.

### Per-user versus collective waiting

AWF computes a candidate value for every missing user, but the action is one
collective action: continue if at least one candidate has positive value,
otherwise stop once and commit the group decision. It does not assign a
separate stopping time to each user. We clarify this point in the algorithm
description and add the full Bellman comparison to show the approximation
introduced by using the maximum one-step candidate value.
