# BCI 및 네트워크 데이터 분석 보고서

## 1. 연구에서 확인하려는 내용

여러 사용자가 같은 BCI 문제에 참여한다고 가정하면, 각 사용자의 분류 결과가 중앙의 fusion node로 전송된다. 하지만 사용자가 이용하는 네트워크가 서로 다르기 때문에 모든 결과가 동시에 도착하지 않는다.

예를 들어 Wi-Fi 사용자의 결과는 빨리 도착하지만, 4G나 LEO 사용자의 결과는 늦게 도착하거나 손실될 수 있다. 중앙에서는 다음 두 가지 중 하나를 선택해야 한다.

1. 지금까지 도착한 사용자 결과만으로 바로 결정한다.
2. 더 정확한 결정을 위해 아직 도착하지 않은 사용자의 결과를 조금 더 기다린다.

AWF는 이 선택을 매 trial마다 다르게 수행하는 방법이다. 현재 BCI 결정이 얼마나 확실한지, 아직 도착하지 않은 사용자가 얼마나 도움이 되는지, 그 응답이 deadline 전에 도착할 가능성이 있는지를 함께 확인한다.

## 2. 사용한 네트워크 데이터

네트워크 데이터는 임의로 만든 지연값이 아니라 실제 측정 자료에서 가져왔다.

### Wi-Fi

Wi-Fi 원본은 패킷 하나마다 전송 지연이 기록된 Parquet 파일이다. 주요 정보는 다음과 같다.

- 패킷을 보낸 시각
- 단말에서 서버까지 걸린 시간
- 서버에서 단말까지 걸린 시간
- 왕복 지연
- Wi-Fi 신호 품질
- 상향·하향 전송률

실험에서는 단말에서 서버까지 걸린 실제 시간을 사용한다. 패킷이 원래 10 ms마다 기록되어야 하는데 중간 기록이 빠져 있으면 해당 패킷은 손실된 것으로 판단한다.

Wi-Fi는 대부분 매우 빠르지만 가끔 큰 지연값이 나타난다. 즉, 평균적으로는 빠르더라도 모든 패킷이 항상 빠른 것은 아니다.

### 5G

5G 원본도 패킷 하나마다 측정값이 기록된 Parquet 파일이다. 단말에서 서버까지의 지연과 함께 RSRP, RSRQ, 주파수 대역 등의 5G 상태 정보가 포함되어 있다.

실험에 사용한 5G 데이터는 대부분 약 5–7 ms에 집중되어 있다. 네 네트워크 중 지연 변화가 가장 작고 안정적이다. Wi-Fi와 동일하게 10 ms 전송 주기에서 빠진 패킷을 손실로 계산한다.

### 4G-LTE

4G 원본은 CSV 파일이다. 각 행에는 다음 정보가 들어 있다.

- 측정 시각과 GPS 위치
- 차량 속도
- LTE 신호 세기와 품질
- 다운로드·업로드 속도
- 평균·최소·최대 ping 지연
- ping 손실률

4G에는 단말에서 서버까지의 한 방향 지연이 직접 제공되지 않는다. 따라서 왕복 지연인 `PINGAVG`를 2로 나누어 한 방향 지연을 근사했다.

예를 들어 평균 ping이 100 ms라면 한 방향 지연을 약 50 ms로 사용한다. 이는 상향 경로와 하향 경로의 지연이 비슷하다고 가정한 값이다.

4G는 네 데이터 중 지연과 손실이 가장 크다. 50 ms deadline에서는 전체 응답의 약 67%만 제시간에 도착한다.

### LEO

LEO 원본은 실제 Starlink 연결에서 측정한 IRTT 텍스트 로그이다. 패킷별로 다음 정보가 기록된다.

- 패킷 순서 번호
- 단말에서 서버까지의 지연
- 서버에서 단말까지의 지연
- 왕복 지연

실험에서는 단말에서 서버까지의 실제 한 방향 지연을 사용한다. 패킷 번호가 중간에 빠지면 해당 패킷을 손실로 판단한다.

LEO 지연은 주로 약 30–50 ms에 분포한다. 대부분의 응답은 50 ms 안에 도착하지만, 링크 상태가 일정 시간 동안 비슷하게 유지되는 특성이 있다.

## 3. 네트워크 데이터 요약

| 네트워크 | 지연 중앙값 | 상위 1% 지연 | 평균 손실률 | 50 ms 안에 도착 |
|---|---:|---:|---:|---:|
| Wi-Fi | 0.50 ms | 10.61 ms | 0.19% | 거의 100% |
| 5G | 5.27 ms | 7.12 ms | 0.48% | 거의 100% |
| 4G-LTE | 45.25 ms | 219.56 ms | 2.15% | 약 67% |
| LEO | 33.60 ms | 73.58 ms | 0.50% | 약 94% |

`상위 1% 지연`은 전체 패킷 중 가장 느린 1%가 시작되는 지점이다. 이 값이 크면 평소에는 빠르더라도 일부 패킷이 매우 늦을 수 있다는 뜻이다.

## 4. 지연과 손실을 실험에 적용한 방법

각 사용자에게 Wi-Fi, 5G, 4G-LTE 또는 LEO 중 하나를 배정한다. 시뮬레이터는 사용자의 BCI 결과가 언제 도착할지를 정하기 위해 해당 네트워크 데이터에서 지연값을 하나 무작위로 뽑는다. 이 값은 시뮬레이션 환경만 알고 있으며 AWF에는 알려주지 않는다.

그다음 해당 네트워크의 손실률에 따라 패킷이 손실되는지를 결정한다.

- 손실되지 않으면 선택된 지연시간 후에 결과가 도착한다.
- 손실되면 결과는 도착하지 않는 것으로 처리한다.

예를 들어 시뮬레이터가 4G 사용자의 실제 도착시간을 60 ms로 정했다고 가정한다. AWF는 이 응답이 60 ms에 도착할 예정이라는 사실을 미리 알지 못한다. AWF가 아는 것은 이 사용자가 4G를 사용한다는 사실, 4G의 과거 지연·손실 분포, 그리고 현재 시각까지 응답이 아직 도착하지 않았다는 사실뿐이다. decision deadline이 50 ms라면 해당 응답은 나중에 60 ms에 도착하더라도 최종 결정에는 사용할 수 없다. 패킷 자체가 손실된 경우에도 사용할 수 없다.

따라서 AWF는 미래의 실제 도착시간을 사용하는 것이 아니라, 현재 시각까지 응답이 도착하지 않았다는 관측과 과거 분포를 이용해 남은 시간 안에 도착할 가능성을 다시 계산한다. 이는 실제 시스템에서 아직 도착하지 않은 패킷의 정확한 미래 도착시간은 알 수 없지만, 과거 측정 통계로 도착 가능성을 추정할 수 있다는 상황을 모사한다.

## 6. 사용자별 BCI 모델 학습 방법

모든 사용자를 하나의 모델로 학습하지 않고, 사용자마다 별도의 BCI 분류기를 학습했다.

### 1단계: EEG 전처리

EEG에서 motor imagery와 관련된 주파수 영역을 사용하기 위해 8–30 Hz band-pass filtering을 적용했다.

### 2단계: 특징 추출

CSP(Common Spatial Pattern)를 사용해 여러 EEG 채널 중 클래스 구분에 도움이 되는 공간 패턴 6개를 추출했다.

쉽게 말하면 CSP는 많은 EEG 채널을 그대로 사용하는 대신, 사용자가 어떤 동작을 상상했는지 구분하기 좋은 조합으로 EEG를 압축하는 과정이다.

### 3단계: 분류기 학습

CSP 특징을 shrinkage LDA에 입력해 클래스를 분류했다. LDA는 각 클래스가 어떤 특징을 가지는지 학습하고, 새로운 EEG trial이 각 클래스일 확률을 출력한다.

예를 들어 3-class 사용자의 출력은 다음과 같다.

```text
left hand  : 0.70
right hand : 0.20
feet       : 0.10
```

이 확률 벡터가 네트워크를 통해 fusion node로 전송되는 사용자의 BCI 결과이다.

## 7. 학습·검증·평가 데이터 분리

각 사용자의 EEG를 다음과 같이 세 부분으로 분리했다.

| 구분 | 약 비율 | 용도 |
|---|---:|---|
| Training | 56% | CSP와 LDA 학습 |
| Validation | 14% | 사용자 신뢰도와 오류 유형 계산 |
| Test | 30% | 최종 fusion 실험 |

Validation 데이터에서는 단순 정확도뿐 아니라 사용자가 어떤 클래스를 어떤 클래스로 자주 잘못 분류하는지 계산한다.

예를 들어 어떤 사용자가 `feet`를 `left hand`로 자주 잘못 분류한다면, AWF는 이 사용자가 현재 혼동 중인 클래스를 구분하는 데 실제로 도움이 되는지를 판단할 수 있다.

Test 데이터는 사용자 신뢰도를 만드는 데 사용하지 않는다. 학습과 calibration이 끝난 뒤의 새로운 EEG 결과로 취급해 최종 평가에만 사용한다.

## 9. 여러 사용자의 BCI 결과를 평가한 방법

세 데이터셋은 여러 사람이 같은 시각에 동일한 자극을 수행한 데이터가 아니다. 따라서 정답 클래스가 같은 서로 다른 사용자 trial을 조합해 하나의 collaborative trial을 구성했다.

예를 들어 정답을 `left hand`로 선택하면:

1. 사용자 S01의 left-hand test trial 하나를 선택한다.
2. 사용자 S02의 left-hand test trial 하나를 선택한다.
3. 나머지 사용자에게도 같은 방식으로 선택한다.
4. 각 사용자의 posterior를 서로 다른 네트워크를 통해 전송한다.
5. 도착한 posterior를 fusion하여 최종 left-hand 여부를 결정한다.

사용자의 EEG 결과는 실제 held-out test trial에서 가져오지만, 사용자들이 실제로 동시에 실험한 것은 아니다. 따라서 이 실험은 사용자별 BCI 성능과 네트워크 지연을 결합한 simulation으로 이해해야 한다.

## 10. 결과가 의미하는 것

- Zhou2016은 사용자 수가 적고 개인 성능이 비교적 균일한 환경이다.
- BNCI2014_001은 사용자별 성능 차이가 커서 reliability-aware fusion의 효과를 확인하기 좋다.
- Weibo2014는 클래스가 많고 개인 분류가 어려워 추가 사용자 결과를 기다릴 가치가 큰 환경이다.
- Wi-Fi와 5G 응답은 대부분 빠르게 도착한다.
- 4G와 LEO 응답은 deadline에 따라 사용 가능 여부가 크게 달라진다.

따라서 AWF는 쉬운 trial에서는 일찍 결정하고, 어려운 trial에서는 도움이 될 가능성이 높은 사용자 응답을 더 기다리는 방식으로 동작한다.

## 11. 네트워크 표본과 실제 실험 횟수

### CDF 표본

CDF 표본은 각 네트워크에서 측정된 지연값을 모아 놓은 자료이다. 쉽게 말하면 지연값이 들어 있는 주머니와 같다. 사용자 응답을 하나 전송할 때마다 그 사용자에게 배정된 네트워크의 주머니에서 지연값 하나를 무작위로 선택한다.

예를 들어 LTE 표본에 `31 ms, 44 ms, 60 ms, 120 ms` 등이 들어 있다면, 서로 다른 trial에서 44 ms, 120 ms, 31 ms 등이 선택될 수 있다. 선택된 표본은 제거하지 않으므로 같은 값이 다시 선택될 수도 있다. 따라서 표본 수가 40,000개라고 해서 실험을 40,000번만 수행한다는 뜻은 아니다.

Wi-Fi, 5G, LEO의 표본 수 40,000개는 원본 전체 크기가 아니라, 경험적 지연분포를 구성하기 위해 원본 측정값 중 최대 40,000개를 보관한 것이다. LTE는 사용 가능한 측정값 944개를 모두 사용한다.

AWF는 이 표본들을 정렬해 과거 지연분포, 즉 경험적 CDF를 만든다. 이를 이용해 “이 네트워크의 응답이 50 ms 이내에 들어올 비율”이나 “현재까지 도착하지 않은 응답이 남은 시간 안에 도착할 가능성”을 계산한다. 다만 AWF는 이번 trial에서 실제로 선택된 지연값은 알지 못한다.

### 연속 구간

연속 구간은 원본 네트워크 측정값의 시간 순서를 유지한 짧은 기록이다. 예를 들어 `5 → 6 → 7 → 48 → 55 → 9 ms`처럼 지연이 시간에 따라 변한 순서가 보존된다.

| 자료 | 쉬운 비유 | 시간 순서 | 현재 용도 |
|---|---|---:|---|
| CDF 표본 | 지연값이 든 주머니 | 보존하지 않음 | 기본 AWF 성능 실험 |
| 연속 구간 | 네트워크 상태를 기록한 동영상 | 보존함 | 별도의 trace replay 및 시간적 강건성 실험 |

기본 성능 실험은 CDF 표본에서 trial마다 지연값을 독립적으로 뽑는다. 따라서 기본 실험을 원본 trace 전체를 시간순으로 그대로 재생한 실험이라고 설명해서는 안 된다. 연속해서 지연이 높아지는 현상을 확인할 때만 별도의 replay 실험에서 연속 구간을 순서대로 사용한다.

### 한 seed에서의 네트워크 적용 과정

1. 사용자마다 Wi-Fi, 5G, LTE, LEO 중 하나를 배정한다. 기본 설정에서 각 네트워크의 배정 확률은 25%이다.
2. 사용자에게 배정된 네트워크는 해당 seed의 모든 BCI trial에서 고정한다.
3. 각 trial마다 사용자별로 해당 네트워크의 CDF 표본에서 지연값 하나를 복원추출한다.
4. 해당 네트워크의 평균 손실률에 따라 패킷 손실 여부를 별도로 추첨한다.
5. 손실되지 않으면 선택된 지연시간 후에 응답이 도착한다.
6. 손실되면 도착시간을 무한대로 설정하여 도착하지 않은 응답으로 처리한다.
7. AWF에는 실제로 선택된 미래 지연값이나 손실 여부를 알려주지 않는다. AWF는 네트워크 종류, 과거 지연·손실 통계, 현재까지 응답이 도착했는지만 이용한다.

### 실험 반복 횟수

| BCI 데이터셋 | 사용자 수 | seed당 collaborative trial | seed당 사용자 응답 생성 |
|---|---:|---:|---:|
| Zhou2016 | 4명 | 131회 | 524회 |
| BNCI2014_001 | 9명 | 173회 | 1,557회 |
| Weibo2014 | 10명 | 150회 | 1,500회 |
| 합계 | 23명 | 454회 | 3,581회 |

실험은 15개 seed로 반복한다. 따라서 정책 하나와 deadline 하나를 평가할 때 collaborative decision은 총 6,810회, 사용자 응답의 지연·손실 추출은 총 53,715회 이루어진다. 50 ms와 100 ms deadline을 모두 평가하면 평가 건수는 각각 13,620회와 107,430회가 된다.

동일한 dataset, seed, deadline에서 비교되는 정책들은 같은 BCI trial과 같은 네트워크 도착 조건을 사용한다. 따라서 특정 정책이 우연히 더 좋은 지연표본을 받아 유리해지는 것을 방지한다.

## 12. 보고 시 밝혀야 하는 한계

1. BCI 사용자들은 실제로 동시에 같은 task를 수행한 것이 아니다.
2. 4G 지연은 실제 one-way 측정이 아니라 RTT를 2로 나눈 근사값이다.
3. 네트워크 손실률은 원본의 평균 손실률을 사용하지만, 여러 패킷이 연속으로 손실되는 현상까지 그대로 재생하지는 않는다.
4. Wi-Fi와 5G는 측정 환경이 양호해 일반 인터넷 환경보다 지연이 낮을 수 있다.
5. 기본 실험은 지연분포에서 독립적으로 표본을 뽑기 때문에 지연의 시간적 자기상관과 지연·손실의 결합관계를 그대로 보존하지 않는다.

## 13. 교수님 보고용 요약

본 연구에서는 세 개의 실제 motor-imagery EEG 데이터셋에서 사용자별 BCI 분류기를 독립적으로 학습했다. 각 모델은 8–30 Hz EEG에서 CSP 특징 6개를 추출하고 shrinkage LDA로 클래스별 확률을 출력한다. Validation 데이터로 사용자별 신뢰도와 오류 특성을 계산하고, 완전히 분리된 test posterior를 collaborative fusion 평가에 사용했다.

네트워크는 실제 Wi-Fi, 5G, 4G-LTE, LEO 측정 자료에서 얻은 end-to-end 지연과 손실을 사용했다. Wi-Fi와 5G는 빠르고, 4G와 LEO는 deadline에 따라 응답 가용성이 달라진다. AWF는 현재 BCI 결정의 확실성, 아직 도착하지 않은 사용자의 신뢰도, deadline 전 도착 가능성을 함께 고려하여 바로 결정할지 더 기다릴지를 선택한다.

기본 네트워크 실험에서는 실제 측정 trace로 경험적 지연분포를 구성하고, 각 사용자 응답마다 해당 분포에서 지연값을 복원추출한다. 사용자별 네트워크 종류는 한 seed 동안 고정하며, 패킷 손실은 네트워크별 평균 손실률에 따라 발생시킨다. 기본 실험은 네트워크별 지연분포 차이를 반영하고, 원본 trace의 시간적 연속성은 별도의 연속 trace replay 실험에서 평가한다.
