# 신규 네트워크 데이터셋 특성 분석

## 1. 데이터 구성

| 데이터 | 출처 | 지연 정의 | 표본 수 | 연속 구간 |
|---|---|---|---:|---:|
| Wi-Fi | KTH wireless-pr3d, IEEE 802.11g IRTT | 실측 uplink one-way delay | 40,000 | 600 |
| 5G | KTH wireless-pr3d, band-n78 5G IRTT | 실측 uplink one-way delay | 40,000 | 120 |
| 4G-LTE | UCC 5G dataset, LTE PINGAVG/2 | RTT의 절반으로 근사한 one-way delay | 944 | 15 |
| LEO | Casparsen Starlink IRTT | 실측 uplink one-way delay | 40,000 | 600 |

Wi-Fi·5G·LEO는 패킷 단위 IRTT에서 얻은 실제 uplink one-way delay를 사용한다. 4G-LTE만 데이터 제약 때문에 PINGAVG/2를 one-way delay로 사용하므로, 4G 수치는 경로 비대칭을 직접 관측한 값이 아니라 RTT 기반 근사값이다.
Wi-Fi·5G·LEO 원본은 40,000개보다 크다. 계산량과 cache 크기를 제한하기 위해 전체 수신 지연 중 최대 40,000개를 무작위 선택하여 CDF 추정에 사용한다. 이 표본은 시간 순서를 보존하지 않으므로, 시간적 분석에는 순서를 유지한 별도의 연속 구간(sequence)을 사용한다.

## 5. 데이터별 대표 특성

- **Wi-Fi:** 중앙 지연은 매우 짧지만 드물게 큰 지연 spike가 나타나는 강한 우측 꼬리 환경.
- **5G:** 지연 분포가 좁고 시간 변화도 작아 네 데이터 중 가장 안정적인 저지연 이동통신 환경.
- **4G-LTE:** 중앙 지연과 분산이 크고 세션 간 차이도 커서 tight deadline에서 가장 불리한 광역 이동통신 환경.
- **LEO:** 평상시 지연은 비교적 집중되어 있지만 위성 링크 특유의 지연 변화와 드문 spike를 포함하는 비지상망 환경.

## 6. 교수님 보고용 요약

이번 실험은 Wi-Fi, 5G, 4G-LTE, LEO의 서로 다른 실제 네트워크 측정 데이터를 사용한다. 네 데이터는 지연 중앙값뿐 아니라 분산, tail latency, 손실, 시간적 변화가 서로 달라 heterogeneous end-to-end 경로 환경을 구성한다. Wi-Fi는 빠르지만 드문 큰 지연값을 포함하고, 5G는 좁고 안정적인 저지연 분포, 4G-LTE는 높은 지연과 큰 변동성, LEO는 집중된 평상시 지연과 위성 링크의 드문 spike를 대표한다. 따라서 동일한 평균 지연만으로 응답 도착을 판단하기 어렵고, deadline과 현재 시점에 따른 조건부 도착 가능성을 고려하는 stop-or-wait 평가에 적합하다.
